# TimeTracker C++

Консольный тайм-трекер для учёта рабочего времени.

## Требования

- Компилятор с поддержкой C++17 (GCC 7+, Clang 5+, MSVC 2017+)
- CMake 3.10+
- ОС: Windows 10/11, Linux (Ubuntu 20.04+), macOS 11+

## Сборка

```bash
# Создание директории сборки
mkdir -p build
cd build

# Генерация файлов сборки
cmake -S .. -B .

# Компиляция
cmake --build . --config Release# TimeTracker2
